# Looping clips for the portfolio grid

Drop a short, silent clip in here named after the project and it replaces that
project's still on the portfolio grid automatically — no code change needed.

    images/clips/reverse.mp4
    images/clips/john-smedley.mp4
    images/clips/matilda-holttum.mp4
    images/clips/historical-palace.mp4
    images/clips/short-film.mp4

`.mp4` is preferred; `.webm` also works. Delete a file and the tile goes back
to its still.

## What to export

- **5 to 8 seconds**, the most striking few seconds of the film
- **No sound** — browsers block audio that starts on its own, and the file is
  smaller without it
- **Roughly 640px wide** and a couple of MB at most. These are small tiles, not
  the film itself
- Portrait or square crops suit the 4:5 tiles best, but anything works

The clips play only while on screen and pause when scrolled past, so a phone
never decodes all five at once. Anyone who has asked their device for less
motion sees the still instead.
